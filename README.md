# 교실 경제 시뮬레이션 프로그램

## 사용 기술 스택
- Frontend: Angular
- Data + 배포: Firebase

## 세부 계획
- 로그인 방식: Google 계정
- 데이터 저장 방식: Firebase Firestore 사용
- 배포: market-mon-51ee9.firebaseapp.com
- 사용 렌더링 방식: CSR(Client-Side Rendering)
- SSR 절대 사용 금지
- 절대 Standalone을 사용하지 말 것. '--standalone=false'을 사용하여 NgModule을 사용할 것.
- 스타일시트 문법: Less 사용 (Scss 혹은 Css 사용 금지)
- 라우팅: Angular Routing 사용
